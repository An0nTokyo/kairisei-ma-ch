# 启动器托盘、主题与单列布局

## 目标

在现有 Windows 启动器上增加最小化到托盘，并把主窗口改成更窄的单列布局。主题默认跟随 Windows 应用的浅色/深色，也可以手动固定。构建方式不变：.NET Framework 4、`csc.exe`、现有程序集引用。服务端启停仍由 `Start-Server.ps1` 和 `Stop-Server.ps1` 负责。

## 范围

改动限于 `cmd/kairi-launcher-winforms/` 和 `tools/powershell/Build-Launcher.ps1`。

不改这些行为：

- 标题栏最小化按钮仍缩到任务栏，不进托盘。
- `--smoke-test` 的检查项和退出码。
- 公网启动前的确认框。
- 运营后台网页。
- 启动器不弹出气泡通知。

## 文件

| 文件 | 职责 |
| --- | --- |
| `Program.cs` | 入口、`--smoke-test`、单实例 |
| `LauncherForm.cs` | 单列主窗口 |
| `ClosePromptForm.cs` | 关闭对话框 |
| `TrayIcon.cs` | 仅在收到托盘时显示图标 |
| `ThemePalette.cs` | 浅色/深色配色、标题栏深色、主题图标 |
| `LauncherPreferences.cs` | 读写偏好 |
| `ServerController.cs` | 保持现有启停和健康检查 |

`Build-Launcher.ps1` 把上述 C# 文件一起编译。不增加程序集引用。托盘图标使用 `System.Windows.Forms.NotifyIcon`。标题栏深色用 `dwmapi.dll` 的 `DwmSetWindowAttribute`。

## 主窗口

默认客户区比现在的 1040×675 更窄，大约能放下一条地址行和整行主按钮。窗口可调整大小。多出来的高度给日志区。继续按 DPI 缩放。

从上到下：

1. 标题栏文字为「乖离性百万亚瑟王 · 服务端启动器」。主题按钮在系统最小化按钮左边。系统按钮仍是最小化、最大化、关闭。
2. 产品图标、标题「乖离性百万亚瑟王」、状态。
3. 副标题「国服本地服务 · Windows x64」。
4. 链接「本项目永久免费 · 从 GitHub 获取」，打开现有项目主页。
5. 「使用场景」下拉框：Android 模拟器、局域网、公网 IP / 域名。
6. 「服务器地址」四个字后面紧跟圆形问号。地址框和「恢复默认」在下一行。
7. 「主端口」输入框。它下面一行是「游戏 {port} · 战斗 {port+1} · Admin 127.0.0.1:{port+2}」。
8. 整行一颗启停按钮。
9. 「Admin面板」和「查看日志」并排。
10. 只读日志。
11. 底部说明：「请完整解压后运行；首次启动会创建全新本地存档。」

不显示「连接」标题，不显示「战斗端口 = 主端口 + 1」那行，不显示「关闭窗口时」。

问号只在悬停时显示说明，说明随使用场景切换，沿用现在的三段文案：

- Android 模拟器：「适用于本机 Android 模拟器。客户端默认地址就是 10.0.2.2，无需改 APK。」
- 局域网：「填写客户端可访问的 IPv4 或域名，支持虚拟局域网及内网穿透。需放行或映射 TCP 主端口和战斗端口。」
- 公网 IP / 域名：「填写这台服务器的公网 IPv4 或域名。需映射 TCP 主端口与战斗端口；Admin 不会公网开放。」

状态文案：

- 没有服务进程：「未运行」。
- 有进程但健康检查未通过，或正在做第一次状态确认：「检测中」。
- 健康通过：「正在运行」。

地址、场景和端口的启用规则保持现在的逻辑：模拟器场景下地址不可编辑；操作进行中这些输入不可编辑。Admin 面板只在健康通过后可点。

原生标题栏若放不进主题按钮，或在高 DPI 下与系统按钮重叠，就把该按钮放到窗口内容区右上角。两种位置都是同一个按钮。

## 启停按钮

只有一颗按钮，占满一行。

| 条件 | 文字 | 能否点击 |
| --- | --- | --- |
| 还没有完成打开后的第一次状态确认 | 确认服务中 | 否 |
| 没有服务进程 | 启动服务 | 是 |
| 已点击启动，健康检查尚未通过 | 确认服务中 | 否 |
| 已有进程，健康检查尚未通过 | 确认服务中 | 否 |
| 健康检查通过，且没有停止操作在进行 | 停止服务 | 是 |
| 正在停止，且服务进程还在 | 停止服务 | 否 |

健康通过前不提供停止。表格自上而下匹配，先命中的一行生效。正在停止且进程还在时，文字保持「停止服务」，不用「确认服务中」。进程消失后回到「启动服务」。

「启动服务」使用强调色，「停止服务」使用危险色，「确认服务中」和正在停止时的「停止服务」使用不可用的灰色。

## 关闭与托盘

标题栏最小化不产生托盘图标。

用户关闭窗口（含 Alt+F4）时：

- 偏好是询问：若窗口缩在任务栏里，先恢复再弹出「关闭启动器」。单选「最小化到托盘」默认选中，另一项是「直接关闭」。下面是「记住选项，下次不再提示」，默认不勾。确定后执行所选；若勾了记住，把所选写入偏好。取消则留在当前窗口，不写偏好。
- 偏好是托盘：不弹窗，直接收到托盘。
- 偏好是退出：不弹窗，按下面的退出规则处理。

收到托盘时，窗口从任务栏消失，只留托盘图标。右键菜单是「显示主页面」和「退出」。双击图标等同于「显示主页面」。主窗口重新显示后，去掉托盘图标。

「直接关闭」和托盘「退出」使用同一条退出规则：

- 没有服务进程：退出启动器。
- 有服务进程：调用现有停止流程，等到这次停止结束再退出。现有停止最长等待约 25 秒。
- 停止失败，或已有启停操作在进行：不退出，重新打开主窗口，并使用现在的失败提示。

关机和注销不弹关闭对话框，也不收进托盘。服务在运行时先停服，等到这次停止结束再退出启动器。停止失败时仍然退出，避免卡住系统关机。服务没在跑时直接退出。

任务管理器结束启动器时，不弹对话框，也不等待停服。

再次启动时若已有实例，新进程直接退出，并把已有窗口拉到前台；窗口在托盘里时先恢复主窗口。

主窗口没有改回关闭偏好的控件。记住「直接关闭」后，关闭对话框不再出现。要恢复为每次询问，把偏好里的 `close_action` 改回 `ask`，或删掉偏好文件。

## 主题

标题栏按钮单击循环：跟随系统 → 浅色 → 深色 → 跟随系统。悬停显示当前档的名字：「跟随系统」「浅色」或「深色」。选择写入偏好。

默认是跟随系统。此时读取 `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme`：缺省或为 1 时用浅色，为 0 时用深色。跟随系统时，用现有约 1.5 秒的状态刷新重新读取；固定浅色或深色后不再跟随。

深色时用系统接口把标题栏改成深色。接口失败时只改窗口内容，标题栏保持系统默认。

### 主题图标

三态共用一套几何。日是黑边、白心的圆。月对应的圆与日同样大，圆心在日的右侧并与日重叠。月牙是日圆内部未被月圆盖住的左边，填色为黑。跟随系统是完整的日圆：黑边，内部左边为这块黑月牙，右边保持白色。浅色只画日。深色只画黑月牙，不画外圈整圆。

浅色标题栏使用上述填色，不加外圈。深色标题栏保持同样的黑白填色，并在黑色边缘外加一圈白色描边，让黑月牙和黑边从深色标题栏上分离出来。

## 偏好

路径：`%AppData%\Kairisei\launcher-preferences.json`。

```json
{
  "close_action": "ask",
  "theme": "system"
}
```

`close_action` 取 `ask`、`tray`、`exit`。`theme` 取 `system`、`light`、`dark`。缺字段或值无法识别时，该字段用默认值：`ask` 和 `system`。文件读不出或写不进时不崩溃，本次运行使用这两个默认值。

## 失败处理

- 偏好损坏：忽略损坏内容，使用默认值。
- 停止失败或启停正在进行：不退出启动器，显示主窗口和现有错误。
- 标题栏深色接口失败：窗口内容仍切换深浅色。
- 关机或注销时停止失败：启动器仍然退出。

## 验证

`tools/powershell/Build-Launcher.ps1` 能编译通过。`--smoke-test` 在具备原来那些文件时仍返回 0，缺少时仍返回 2。

手动确认：

- 最小化按钮缩到任务栏，不出现托盘图标。
- 关闭对话框默认选中「最小化到托盘」；取消不改变窗口。
- 收到托盘后，任务栏没有主窗口；双击和「显示主页面」能恢复，恢复后托盘图标消失。
- 记住托盘后，再点关闭直接进托盘。记住直接关闭后，服务在运行时会先停服再退出；服务没在跑时只退出启动器。
- 服务未运行时直接关闭只退出启动器。停止失败时启动器仍打开并显示失败。
- 第二次启动激活已有窗口。
- 打开后的第一次确认、启动后健康通过前、已有进程但健康未通过，按钮都是置灰的「确认服务中」。健康通过后变为可点的「停止服务」。
- 主题按钮按跟随系统、浅色、深色循环。深色标题栏上的图标带白色外圈，填色不变。
- 问号悬停文案随使用场景变化。
- 关机或注销时启动器会等待停服结束。
